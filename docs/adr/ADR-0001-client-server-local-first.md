# ADR-0001 — معماری Client–Server با هسته Local-First

- Status: Accepted
- Date: 2026-08-25
- Phase: 0 (بازنویسی تصمیم §17 سند)
- Blocks: فازهای 1..7

## زمینه
نسخه ۱ یک اپ دسکتاپ تماماً آفلاین بود؛ بدون سرور، لایسنس/ RBAC/sync/مدل درآمدی ممکن نبود و Data Flywheel وجود نداشت.

## تصمیم
معماری Client–Server با هسته Local-First: API مرکزی (NestJS) + Local DB سمت کلاینت + Outbox Sync. تحلیل تصویر همیشه لوکال اجرا می‌شود.

## جایگزین‌های ردشده
- دسکتاپ تماماً آفلاین مثل v1 — مانع مدل درآمد، لایسنس، چندکاربره و ML

## پیامدها
- مثبت: فروش پلن از روز اول · ایزوله‌سازی tenant · توزیع مدل ML
- منفی: هزینه نگهداری سرور + پیچیدگی sync (پذیرفته‌شده با ADR-0004)
