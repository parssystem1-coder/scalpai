### AUD-5 | اعمال ضرایب کالیبره‌شدهٔ heuristic (اقدام فعلی D2 نقشه‌راه)
- **شرح:** لایهٔ شواهد موج ۴ ساخته شد (`src/lib/heuristicCalibration.ts` + پنل) ولی
  ضرایب مشترک (`shared/scalp-constants.json` ← `heuristicConstants.ts` ←
  `python/analyze.py`) آگاهانه بازنویسی نشد. نقشه‌راه دو پیش‌شرط دارد: parity عددی
  موتورها + معیار بازگشت «بهبود macro-F1 < ۲٪ در بازآموزی».
- **پیش‌شرط اجرا:**
  1. گیج ۱۵۰ نمونهٔ متخصص سبز باشد (اکنون در کلینیک واقعی جمع نشده).
  2. **هارنس parity عددی** ساخته شود: ورودی ثابت → خروجی TS/Python یکسان در تلرانس
     (الگوی موجود: `scripts/check-shared-constants.cjs` و `engineParity.test.ts`).
  3. جریان «کاندید ضرایب → بازآموزی کامل → مقایسهٔ macro-F1 روی holdout» با قانون
     بازگشت <۲٪ + بکاپ ضرایب فعلی.
- **شاهد:** `src/lib/heuristicCalibration.ts`، پنل `HeuristicCalibrationPanel.tsx`،
  گارد `scripts/check-shared-constants.cjs`؛ توجیه در `docs/موج-۴-گزارش-اجرا.md`.
- **معیار پذیرش:** گزارش K-Fold نشان‌دهندهٔ بهبود پایدار؛ تست parity سبز؛ گارد
  ثابت‌ها سبز؛ اگر بهبود < ۲٪ → بازگشت به ضرایب قبلی (سند در commit message).

## ۷. نکتهٔ محیطی برای چت‌های بعدی (درس ثبت‌شده)

sandbox هر نوبت ممکن است git metadata را روی `main` بازنشانی کند (working tree
معمولاً دست‌نخورده می‌ماند). **قبل از هر کامیت**: اگر `git log -1` حاوی sha کامیت‌های
موج‌ها نیست، `git fetch origin arena/019fb329-scalpai` و سپس
`git merge --ff-only FETCH_HEAD` کن (ff-only هیچ تضاد یا بازنویسی‌ای نمی‌کند چون
محتوا یکی است) و بعد کامیت کن. دفعهٔ قبل که این چک جا افتاد، به‌گر اشتباه با استخراج
پچ اصلاح شد — تکرارش نکن.
